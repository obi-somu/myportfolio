# Clinton Obi - Portfolio

This repository contains the code for Clinton Obi's personal portfolio website. The website showcases his skills, experience, projects, certifications, and languages in a clean and responsive design.

## Features
- Responsive design for all devices
- Sections for About, Experience, Projects, Certifications, Skills, Languages, and Contact
- Downloadable resume
- Links to LinkedIn and GitHub

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- Font Awesome Icons

## How to Run
1. Clone the repository.
2. Open `index.html` in your browser.
